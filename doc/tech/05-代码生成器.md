# 代码生成器

## 功能概述

代码生成器可以根据数据库表结构，自动生成 Controller、Service、Mapper、Domain、页面等全套代码，大幅减少重复编码工作。

## 使用流程

### 1. 导入表结构

- 进入"代码生成"页面，点击"导入"按钮
- 选择需要生成代码的数据库表（可多选）
- 系统自动读取表结构和字段信息，生成 gen_table 和 gen_table_column 记录

### 2. 编辑生成配置

- 在代码生成列表中点击"编辑"
- 配置生成信息：
  - 表名称、表描述（自动读取）
  - 类名称、功能名称、功能作者
  - 生成模板：单表/树表/主子表
  - 生成包路径、模块名、业务名
  - 生成方式：zip下载/自定义路径
  - 前端表单列数
  - 其他选项（如树编码字段、树名称字段等）

### 3. 编辑字段配置

- 切换到"字段信息"标签
- 为每个字段配置：
  - 插入/编辑/列表/查询是否显示
  - 查询方式：精确/模糊/范围/大于/小于
  - 显示类型：文本框/文本域/下拉框/单选框/复选框/日期/富文本
  - 字典类型：关联的字典编码
  - Java类型、Java字段（可修改）

### 4. 预览代码

- 点击"预览"按钮查看生成的代码
- 可逐个查看 Controller、Service、Mapper、Domain、页面代码

### 5. 生成代码

- **下载方式**：点击"生成代码"，下载 zip 压缩包
- **自定义路径**：代码直接生成到项目指定路径（需配置 gen_path）
- **批量生成**：勾选多个表，点击"批量生成"

## 生成内容

### 单表模板（crud）

| 文件 | 路径模板 | 说明 |
|------|---------|------|
| Controller.java | {packageName}/controller/{moduleName}/{ClassName}Controller.java | 控制器 |
| Service.java | {packageName}/service/I{ClassName}Service.java | 服务接口 |
| ServiceImpl.java | {packageName}/service/impl/{ClassName}ServiceImpl.java | 服务实现 |
| Mapper.java | {packageName}/mapper/{ClassName}Mapper.java | Mapper接口 |
| Mapper.xml | resources/mapper/{moduleName}/{ClassName}Mapper.xml | Mapper XML |
| Domain.java | {packageName}/domain/{ClassName}.java | 实体类 |
| list.html | templates/{moduleName}/{businessName}/list.html | 列表页面 |
| add.html | templates/{moduleName}/{businessName}/add.html | 新增页面 |
| edit.html | templates/{moduleName}/{businessName}/edit.html | 编辑页面 |
| sql.vm | {ClassName}.sql | 菜单SQL |

### 树表模板（tree）

额外生成 tree.html 页面，列表页使用树形结构展示。

### 主子表模板（sub）

额外生成子表 Domain 类（sub-domain.java.vm），列表页使用主从结构展示。

## 模板位置

所有 Velocity 模板位于 `ruoyi-generator/src/main/resources/vm/` 目录：

```
vm/
├── html/
│   ├── add.html.vm        新增页面模板
│   ├── edit.html.vm       编辑页面模板
│   ├── list.html.vm       列表页面模板
│   ├── list-tree.html.vm  树表列表模板
│   ├── tree.html.vm       树选择模板
│   └── view.html.vm       详情页面模板
├── java/
│   ├── controller.java.vm Controller模板
│   ├── domain.java.vm     Domain模板
│   ├── mapper.java.vm     Mapper接口模板
│   ├── service.java.vm    Service接口模板
│   ├── serviceImpl.java.vm Service实现模板
│   └── sub-domain.java.vm 子表Domain模板
└── sql/
    └── sql.vm             菜单SQL模板
```

## 配置文件

**generator.yml**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| gen.author | ruoyi | 代码生成作者名（出现在注释中） |
| gen.packageName | com.ruoyi.system | 默认生成包路径 |
| gen.autoRemovePre | false | 是否自动去除表前缀 |
| gen.tablePrefix | sys_ | 表前缀（autoRemovePre=true时生效，生成类名不包含前缀） |
| gen.allowOverwrite | false | 是否允许覆盖已有文件 |

## 生成后必做

1. **执行菜单SQL**：生成的 sql.vm 包含菜单插入语句，需在数据库中执行
2. **刷新页面**：执行SQL后刷新页面，新菜单才会出现
3. **检查权限**：为新菜单分配角色权限
4. **调整代码**：
   - 检查 Domain 的校验注解是否完整（@NotBlank、@Size 等）
   - 检查列表页的搜索条件是否合理
   - 检查字典类型是否正确关联
   - 根据业务需求添加数据权限（@DataScope）
   - 根据业务需求添加操作日志（@Log）
5. **同步数据库**：如果表结构变更，使用"同步"功能更新生成配置

## 创建表功能

- 通过 SQL 语句在线创建数据库表
- 需要 admin 角色（@RequiresRoles("admin")）
- 创建后自动导入表结构到代码生成器
