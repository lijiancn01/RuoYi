## 公共字段说明

| 字段 | 类型 | 说明 | 自动填充 |
|------|------|------|---------|
| create_by | varchar(64) | 创建者 | Service层设置 `ShiroUtils.getLoginName()` |
| create_time | datetime | 创建时间 | 数据库/MyBatis自动填充 |
| update_by | varchar(64) | 更新者 | Service层设置 `ShiroUtils.getLoginName()` |
| update_time | datetime | 更新时间 | 数据库/MyBatis自动填充 |
| remark | varchar(500) | 备注 | 用户输入 |
| del_flag | char(1) | 删除标志 | 0=存在,2=删除（逻辑删除） |

## 初始数据说明

系统初始化时包含以下关键初始数据：

### 默认用户

| login_name | user_name | 说明 |
|------------|-----------|------|
| admin | 若依管理员 | 超级管理员，userId=1，拥有所有权限 |

### 默认角色

| role_name | role_key | 说明 |
|-----------|----------|------|
| 超级管理员 | admin | roleId=1，拥有 `*:*:*` 全权限，不可删除/修改 |
| 普通角色 | common | 普通用户角色 |

### 默认部门

| dept_name | 说明 |
|-----------|------|
| 若依科技 | 顶级部门，deptId=100 |
| 深圳总公司 | 二级部门 |
| 长沙总公司 | 二级部门 |

### 默认岗位

| post_code | post_name | 说明 |
|-----------|-----------|------|
| ceo | 董事长 | — |
| se | 项目经理 | — |
| hr | 人力资源 | — |
| user | 普通员工 | — |

### 系统字典类型（部分）

| dict_type | dict_name | 说明 |
|-----------|-----------|------|
| sys_user_sex | 用户性别 | 0=男,1=女,2=未知 |
| sys_show_hide | 菜单状态 | 0=显示,1=隐藏 |
| sys_normal_disable | 系统正常停用 | 0=正常,1=停用 |
| sys_job_status | 任务状态 | 0=正常,1=暂停 |
| sys_job_group | 任务分组 | DEFAULT=默认分组 |
| sys_yes_no | 系统是否 | Y=是,N=否 |
| sys_notice_type | 通知类型 | 1=通知,2=公告 |
| sys_notice_status | 通知状态 | 0=正常,1=关闭 |
| sys_oper_type | 操作类型 | 操作日志业务类型 |
| sys_common_status | 系统状态 | 0=成功,1=失败 |

### 系统参数（部分）

| config_key | 说明 | 默认值 |
|------------|------|--------|
| sys.account.captchaEnabled | 是否开启验证码 | true |
| sys.account.registerUser | 是否开启自注册 | false |
| sys.user.initPassword | 初始密码 | 123456 |

### 默认菜单

系统初始化时包含完整的菜单树，涵盖系统管理、系统监控、系统工具三大模块，每个模块下有对应的子菜单和按钮权限。
