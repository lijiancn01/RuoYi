# 02-架构设计

## 分层架构

系统采用经典的三层架构，严格遵循 Controller → Service → Mapper 调用链：

```
浏览器请求
    │
    ▼
Shiro过滤器链（认证/授权/Session/XSS/CSRF）
    │
    ▼
Controller（ruoyi-admin）
    │  接收请求、参数校验、权限校验、调用Service
    ▼
Service（ruoyi-system / ruoyi-quartz / ruoyi-generator）
    │  业务逻辑处理、事务控制、数据权限过滤
    ▼
Mapper（ruoyi-system / ruoyi-quartz / ruoyi-generator）
    │  数据访问、SQL执行
    ▼
MySQL数据库
```

各层职责：

| 层 | 所在模块 | 职责 | 规范 |
|----|---------|------|------|
| Controller | ruoyi-admin | 接收请求、参数校验（@Validated）、权限控制（@RequiresPermissions）、调用Service、返回结果 | 不写业务逻辑，只做转发和包装 |
| Service | ruoyi-system等 | 业务逻辑处理、事务管理（@Transactional）、数据权限（@DataScope） | 接口与实现分离，接口在service包，实现在service/impl包 |
| Mapper | ruoyi-system等 | 数据访问，SQL定义在XML文件中 | 接口在mapper包，XML在resources/mapper目录 |

## 请求流转

一个完整的HTTP请求从浏览器到响应的流转过程：

```
1. 浏览器发起请求
2. Shiro过滤器链（按顺序执行）：
   ├── anon            → 静态资源直接放行（/css/**, /js/**, /img/**, /ajax/**, /fonts/** 等）
   ├── anon            → 验证码放行（/captcha/captchaImage**）
   ├── @Anonymous注解  → 标记了@Anonymous的接口放行
   ├── logout          → 退出登录（/logout）
   ├── anon+captcha    → 登录/注册（/login, /register），需验证码校验
   └── user+其他       → 需认证的请求（/**），依次经过：
       ├── user              → Shiro认证检查（必须登录）
       ├── kickout           → 同账号互踢检查
       ├── onlineSession     → 在线Session校验
       ├── syncOnlineSession → 同步Session到数据库
       └── csrfValidateFilter→ CSRF校验（默认关闭）
3. 进入Controller方法
   ├── @RequiresPermissions → 权限校验（AOP拦截，UserRealm授权）
   ├── @RequiresRoles       → 角色校验
   ├── @Log                 → 操作日志记录（LogAspect AOP）
   ├── @DataScope           → 数据权限过滤（DataScopeAspect AOP）
   ├── @RepeatSubmit        → 防重提交检查（SameUrlDataInterceptor）
   ├── @DataSource          → 数据源切换（DataSourceAspect AOP）
   └── @Xss                 → XSS过滤（校验级别）
4. Controller调用Service处理业务
5. Service调用Mapper访问数据库
6. 返回结果（AjaxResult / TableDataInfo / 页面）
```

## 模块依赖关系

```
                    ruoyi-admin（启动入口 + Controller + 页面）
                    ┌────────┼────────┐
                    │        │        │
                    ▼        ▼        ▼
            ruoyi-framework  ruoyi-quartz  ruoyi-generator
            （框架核心）     （定时任务）    （代码生成）
                    │        │        │
                    ▼        │        │
            ruoyi-system     │        │
            （系统业务）      │        │
                    │        │        │
                    ▼        ▼        ▼
                ruoyi-common（通用工具）
```

**依赖规则**：
- common 不依赖任何其他模块
- system 只依赖 common
- framework 依赖 system 和 common
- quartz、generator 只依赖 common
- admin 依赖所有模块

## 核心基类

### BaseController

**文件**：[BaseController.java](../../ruoyi-common/src/main/java/com/ruoyi/common/core/controller/BaseController.java)

所有 Controller 的父类，提供以下公共方法：

| 方法 | 返回类型 | 说明 |
|------|---------|------|
| `startPage()` | void | 开启分页（调用PageHelper），在查询列表前调用 |
| `startOrderBy()` | void | 开启排序（防SQL注入） |
| `clearPage()` | void | 清理分页线程变量 |
| `getDataTable(List<?>)` | TableDataInfo | 封装分页结果 |
| `toAjax(int rows)` | AjaxResult | 根据影响行数返回成功/失败（rows>0成功） |
| `toAjax(boolean result)` | AjaxResult | 根据布尔值返回成功/失败 |
| `success()` | AjaxResult | 返回成功消息 |
| `error()` | AjaxResult | 返回失败消息 |
| `success(String msg)` | AjaxResult | 返回自定义成功消息 |
| `error(String msg)` | AjaxResult | 返回自定义错误消息 |
| `redirect(String url)` | String | 页面跳转 |
| `getSysUser()` | SysUser | 获取当前登录用户 |
| `getUserId()` | Long | 获取当前登录用户ID |
| `getLoginName()` | String | 获取当前登录用户名 |

### BaseEntity

**文件**：[BaseEntity.java](../../ruoyi-common/src/main/java/com/ruoyi/common/core/domain/BaseEntity.java)

所有业务实体的父类，提供以下公共字段：

| 字段 | 类型 | 说明 | 特殊处理 |
|------|------|------|---------|
| `searchValue` | String | 搜索值 | @JsonIgnore |
| `createBy` | String | 创建者 | — |
| `createTime` | Date | 创建时间 | @JsonFormat("yyyy-MM-dd HH:mm:ss", GMT+8) |
| `updateBy` | String | 更新者 | — |
| `updateTime` | Date | 更新时间 | @JsonFormat("yyyy-MM-dd HH:mm:ss", GMT+8) |
| `remark` | String | 备注 | — |
| `params` | Map<String, Object> | 请求参数（含dataScope） | @JsonInclude(NON_EMPTY)，null时自动初始化为HashMap |

**params 字段用途**：数据权限切面将拼接的SQL条件放入 `params["dataScope"]`，供 Mapper XML 引用。

### AjaxResult

**文件**：[AjaxResult.java](../../ruoyi-common/src/main/java/com/ruoyi/common/core/domain/AjaxResult.java)

统一返回结果类，继承 HashMap，状态码定义：

| 状态 | code | 说明 |
|------|------|------|
| SUCCESS | 0 | 成功 |
| WARN | 301 | 警告 |
| ERROR | 500 | 失败 |

常用工厂方法：

| 方法 | 说明 |
|------|------|
| `AjaxResult.success()` | 成功，默认消息"操作成功" |
| `AjaxResult.success(Object data)` | 成功，携带数据 |
| `AjaxResult.success(String msg, Object data)` | 成功，自定义消息+数据 |
| `AjaxResult.error()` | 失败，默认消息"操作失败" |
| `AjaxResult.error(String msg)` | 失败，自定义消息 |
| `AjaxResult.warn(String msg)` | 警告 |

### TableDataInfo

分页数据封装类：

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | long | 总记录数 |
| `rows` | List<?> | 数据列表 |
| `code` | int | 状态码 |
| `msg` | String | 消息 |

## 通用机制

### 分页机制

**使用方式**：Controller 中调用 `startPage()` 后紧跟查询方法

```java
startPage();  // 开启分页，从请求参数中获取pageNum和pageSize
List<SysUser> list = userService.selectUserList(user);  // PageHelper自动拦截
return getDataTable(list);  // 封装为TableDataInfo
```

**请求参数**：`pageNum`（页码）、`pageSize`（每页大小）、`orderByColumn`（排序列）、`isAsc`（升序/降序）

### 操作日志

**触发方式**：方法上加 `@Log` 注解

```java
@Log(title = "用户管理", businessType = BusinessType.INSERT)
@PostMapping("/add")
public AjaxResult addSave(SysUser user) { ... }
```

**记录内容**：操作人、请求URL、IP、方法名、请求参数（排除password等敏感字段）、响应结果、耗时、异常信息

**异步保存**：通过 AsyncManager 异步写入 sys_oper_log 表

### 数据权限

**触发方式**：Service 方法上加 `@DataScope` 注解

```java
@DataScope(deptAlias = "d", userAlias = "u")
public List<SysUser> selectUserList(SysUser user) { ... }
```

**过滤规则**：根据用户角色的 dataScope 值自动拼接SQL条件，详见 [04-基础设施](04-基础设施.md)

### 防重提交

**触发方式**：Controller 方法上加 `@RepeatSubmit` 注解

```java
@RepeatSubmit(interval = 10000)  // 10秒内不允许重复提交
@PostMapping("/add")
public AjaxResult addSave(SysUser user) { ... }
```

**判断逻辑**：同一URL + 相同请求参数 + 间隔时间小于配置值 → 判定为重复提交

### Excel导入导出

**触发方式**：Domain 字段上加 `@Excel` 注解

```java
@Excel(name = "用户名")
private String userName;
```

**导出**：调用 `ExcelUtil.writeExcel()` 生成Excel文件
**导入**：调用 `ExcelUtil.readExcel()` 解析Excel文件

### 字典缓存

**机制**：系统启动时加载所有字典数据到 EhCache 缓存，通过 `DictUtils` 工具类获取

```java
// 获取字典标签
DictUtils.getDictLabel("sys_user_sex", "0");  // 返回"男"
// 获取字典列表
DictUtils.getDictCache("sys_user_sex");  // 返回List<SysDictData>
```

**刷新**：修改字典后调用 `refreshCache()` 刷新缓存
