# 01-项目概览

## 项目简介

若依（RuoYi）管理系统是一套基于 Spring Boot + Shiro + MyBatis + Thymeleaf 的后台管理系统，提供用户管理、角色管理、菜单管理、部门管理、岗位管理、字典管理、参数配置、通知公告、操作日志、登录日志、在线用户、定时任务、代码生成等基础功能，适用于快速构建企业级后台管理系统。

## 模块划分

### Maven 模块结构

```
ruoyi (父POM)
├── ruoyi-common        通用工具模块
├── ruoyi-framework     框架核心模块
├── ruoyi-system        系统业务模块
├── ruoyi-quartz        定时任务模块
├── ruoyi-generator     代码生成模块
└── ruoyi-admin         启动与Web模块
```

### 模块职责

| 模块 | 职责 | 说明 |
|------|------|------|
| **ruoyi-common** | 通用工具 | 注解、常量、枚举、异常、工具类、核心基类（BaseController/BaseEntity/AjaxResult）、核心实体（SysUser/SysRole/SysMenu/SysDept/SysDictData/SysDictType） |
| **ruoyi-framework** | 框架核心 | Shiro配置、数据源配置、AOP切面（日志/数据权限/数据源）、全局异常处理、Shiro Realm、登录/密码服务、缓存/字典/权限服务 |
| **ruoyi-system** | 系统业务 | 用户/角色/菜单/部门/岗位/字典/配置/通知/日志等业务Service和Mapper |
| **ruoyi-quartz** | 定时任务 | Quartz任务调度、任务管理、任务日志 |
| **ruoyi-generator** | 代码生成 | 代码生成器、表结构导入、代码预览与下载 |
| **ruoyi-admin** | 启动入口 | Controller层、页面模板、静态资源、配置文件、启动类 |

### 模块依赖关系

```
ruoyi-admin
  ├── ruoyi-framework
  │     ├── ruoyi-system
  │     │     └── ruoyi-common
  │     └── ruoyi-common
  ├── ruoyi-quartz
  │     └── ruoyi-common
  └── ruoyi-generator
        └── ruoyi-common
```

依赖方向：admin → framework → system → common（从上到下依赖，common 无外部依赖）

## 配置文件说明

### application.yml 核心配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `ruoyi.name` | 系统名称 | RuoYi |
| `ruoyi.version` | 系统版本 | 4.8.3 |
| `ruoyi.demoEnabled` | 演示模式开关 | true |
| `ruoyi.profile` | 文件上传路径 | D:/ruoyi/uploadPath |
| `ruoyi.addressEnabled` | IP地址解析开关 | false |
| `server.port` | 服务端口 | 80 |
| `user.password.maxRetryCount` | 密码重试最大次数 | 5 |
| `spring.servlet.multipart.max-file-size` | 单文件上传大小限制 | 10MB |
| `spring.servlet.multipart.max-request-size` | 总上传大小限制 | 20MB |
| `mybatis.typeAliasesPackage` | MyBatis类型别名包 | com.ruoyi.**.domain |
| `mybatis.mapperLocations` | Mapper XML位置 | classpath*:mapper/**/*Mapper.xml |
| `pagehelper.helperDialect` | 分页方言 | mysql |
| `shiro.user.captchaEnabled` | 验证码开关 | true |
| `shiro.user.captchaType` | 验证码类型 | math（数字计算） |
| `shiro.session.expireTime` | Session超时(分钟) | 30 |
| `shiro.session.maxSession` | 同一用户最大会话数 | -1（不限制） |
| `shiro.rememberMe.enabled` | 记住我开关 | true |
| `xss.enabled` | XSS过滤开关 | true |
| `xss.excludes` | XSS排除路径 | /system/notice/* |
| `csrf.enabled` | CSRF防护开关 | false |

### application-druid.yml

数据源配置文件，包含主数据源和从数据源（可选）的连接信息，使用 Druid 连接池。

## 启动方式

1. 初始化数据库：执行 SQL 脚本创建表和初始数据
2. 修改 `application-druid.yml` 中的数据库连接信息
3. 运行 [RuoYiApplication.java](../../ruoyi-admin/src/main/java/com/ruoyi/RuoYiApplication.java) 启动类
4. 访问 `http://localhost` 进入系统
5. 默认管理员账号：admin / admin123
