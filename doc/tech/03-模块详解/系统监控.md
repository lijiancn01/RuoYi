# 系统监控模块

## 功能清单

| 功能 | 说明 | 权限标识 | 菜单路径 |
|------|------|---------|---------|
| 在线用户 | 查看当前在线用户，支持强制退出 | monitor:online:* | 系统监控/在线用户 |
| 操作日志 | 记录和查询用户操作日志 | monitor:operlog:* | 系统监控/操作日志 |
| 登录日志 | 记录和查询用户登录日志 | monitor:logininfor:* | 系统监控/登录日志 |
| 缓存监控 | 查看EhCache缓存信息，支持清理 | monitor:cache:view | 系统监控/缓存监控 |
| 服务器监控 | 查看服务器CPU/内存/JVM信息 | monitor:server:view | 系统监控/服务器监控 |
| 数据监控 | Druid连接池监控页面 | monitor:data:view | 系统监控/数据监控 |

## 一、在线用户

### 代码定位

| 层 | 文件路径 |
|----|---------|
| Controller | ruoyi-admin/src/main/java/com/ruoyi/web/controller/monitor/SysUserOnlineController.java |
| Service接口 | ruoyi-system/src/main/java/com/ruoyi/system/service/ISysUserOnlineService.java |
| Service实现 | ruoyi-system/src/main/java/com/ruoyi/system/service/impl/SysUserOnlineServiceImpl.java |
| Mapper接口 | ruoyi-system/src/main/java/com/ruoyi/system/mapper/SysUserOnlineMapper.java |
| Mapper XML | ruoyi-system/src/main/resources/mapper/system/SysUserOnlineMapper.xml |
| Domain | ruoyi-system/src/main/java/com/ruoyi/system/domain/SysUserOnline.java |
| 页面 | ruoyi-admin/src/main/resources/templates/monitor/online/online.html |

### 接口清单

| 接口路径 | 方法 | 说明 | 权限标识 |
|---------|------|------|---------|
| /monitor/online | GET | 在线用户页面 | monitor:online:view |
| /monitor/online/list | POST | 查询在线用户列表 | monitor:online:list |
| /monitor/online/batchForceLogout | POST | 批量强退用户 | monitor:online:batchForceLogout **或** monitor:online:forceLogout |

### 业务规则与边界条件

- **在线用户数据来源**：从 EhCache 缓存中获取活跃的 Session 列表，而非直接查数据库
- **强退逻辑**：将 Session 标记为已过期，用户下次请求时会被 Shiro 拦截并跳转登录页
- **权限OR逻辑**：batchForceLogout 接口权限使用 Logical.OR，满足 batchForceLogout 或 forceLogout 任一即可
- **Session同步**：Session 信息定期同步到 sys_user_online 表（由 Shiro 的 SessionDAO 实现）
- **管理员不可强退**：当前登录用户自己不可被强退

### 数据模型

**sys_user_online 表**

| 字段 | 类型 | 必填 | 说明 | 边界/约束 |
|------|------|------|------|----------|
| sessionId | varchar(50) | 是 | Session ID | 主键 |
| login_name | varchar(50) | 否 | 登录名称 | — |
| dept_name | varchar(50) | 否 | 部门名称 | — |
| ipaddr | varchar(128) | 否 | 登录IP | — |
| login_location | varchar(255) | 否 | 登录地点 | — |
| browser | varchar(50) | 否 | 浏览器 | — |
| os | varchar(50) | 否 | 操作系统 | — |
| status | varchar(10) | 否 | 在线状态 | on_line=在线,off_line=离线 |
| start_timestamp | datetime | 否 | Session创建时间 | — |
| last_access_time | datetime | 否 | 最后访问时间 | — |
| expire_time | int | 否 | 过期时间(秒) | — |
| session_data | blob | 否 | Session数据 | BlobTypeHandler |

## 二、操作日志

### 代码定位

| 层 | 文件路径 |
|----|---------|
| Controller | ruoyi-admin/src/main/java/com/ruoyi/web/controller/monitor/SysOperlogController.java |
| Service接口 | ruoyi-system/src/main/java/com/ruoyi/system/service/ISysOperLogService.java |
| Service实现 | ruoyi-system/src/main/java/com/ruoyi/system/service/impl/SysOperLogServiceImpl.java |
| Mapper接口 | ruoyi-system/src/main/java/com/ruoyi/system/mapper/SysOperLogMapper.java |
| Mapper XML | ruoyi-system/src/main/resources/mapper/system/SysOperLogMapper.xml |
| Domain | ruoyi-system/src/main/java/com/ruoyi/system/domain/SysOperLog.java |
| 列表页面 | ruoyi-admin/src/main/resources/templates/monitor/operlog/operlog.html |
| 详情页面 | ruoyi-admin/src/main/resources/templates/monitor/operlog/detail.html |

### 接口清单

| 接口路径 | 方法 | 说明 | 权限标识 |
|---------|------|------|---------|
| /monitor/operlog | GET | 操作日志页面 | monitor:operlog:view |
| /monitor/operlog/list | POST | 查询日志列表 | monitor:operlog:list |
| /monitor/operlog/export | POST | 导出日志Excel | monitor:operlog:export |
| /monitor/operlog/remove | POST | 删除日志 | monitor:operlog:remove |
| /monitor/operlog/detail/{operId} | GET | 日志详情 | monitor:operlog:detail |
| /monitor/operlog/clean | POST | 清空日志 | monitor:operlog:remove |

### 业务规则与边界条件

- **自动记录**：通过 @Log 注解 + LogAspect 切面自动记录，无需手动调用
- **异步写入**：通过 AsyncManager 异步写入数据库，不阻塞业务方法
- **敏感字段过滤**：password、oldPassword、newPassword、confirmPassword 字段不记录到 oper_param
- **内容截断**：请求参数、响应结果、异常信息均截取前2000字符
- **过滤对象**：MultipartFile、HttpServletRequest、HttpServletResponse、BindingResult 不记录
- **清空操作**：clean 接口清空全部日志，不可恢复

### 数据模型

**sys_oper_log 表**

| 字段 | 类型 | 必填 | 说明 | 边界/约束 |
|------|------|------|------|----------|
| oper_id | bigint | 是 | 日志主键 | 主键，自增 |
| title | varchar(50) | 否 | 模块标题 | @Log的title值 |
| business_type | int | 否 | 业务类型 | 0=其它,1=新增,2=修改,3=删除,4=授权,5=导出,6=导入,7=强退,8=生成代码,9=清空 |
| method | varchar(200) | 否 | 方法名称 | 类名.方法名() |
| request_method | varchar(10) | 否 | 请求方式 | GET/POST/PUT/DELETE |
| operator_type | int | 否 | 操作类别 | 0=其它,1=后台用户,2=手机端用户 |
| oper_name | varchar(50) | 否 | 操作人员 | 当前登录用户名 |
| dept_name | varchar(50) | 否 | 部门名称 | — |
| oper_url | varchar(255) | 否 | 请求URL | — |
| oper_ip | varchar(128) | 否 | 主机地址 | — |
| oper_location | varchar(255) | 否 | 操作地点 | — |
| oper_param | varchar(2000) | 否 | 请求参数 | 截取前2000字符 |
| json_result | varchar(2000) | 否 | 返回参数 | 截取前2000字符 |
| status | int | 否 | 操作状态 | 0=正常,1=异常 |
| error_msg | varchar(2000) | 否 | 错误消息 | 截取前2000字符 |
| oper_time | datetime | 否 | 操作时间 | — |
| cost_time | bigint | 否 | 消耗时间(毫秒) | — |

| /monitor/logininfor/export | POST | 导出日志Excel | monitor:logininfor:export |

- **自动记录**：登录成功/失败时通过 AsyncFactory 异步记录

- **密码锁定**：密码错误超过 maxRetryCount（默认5次）后账户锁定10分钟
- **清空操作**：clean 接口清空全部日志，不可恢复

## 四、缓存监控

### 代码定位

| 层 | 文件路径 |
|----|---------|
| Controller | ruoyi-admin/src/main/java/com/ruoyi/web/controller/monitor/CacheController.java |
| Service | ruoyi-framework/src/main/java/com/ruoyi/framework/web/service/CacheService.java |
| 页面 | ruoyi-admin/src/main/resources/templates/monitor/cache/cache.html |

### 接口清单

| 接口路径 | 方法 | 说明 | 权限标识 |
|---------|------|------|---------|
| /monitor/cache | GET | 缓存监控页面 | monitor:cache:view |
| /monitor/cache/getNames | POST | 获取缓存名称列表 | monitor:cache:view |
| /monitor/cache/getKeys | POST | 获取缓存键名列表 | monitor:cache:view |
| /monitor/cache/getValue | POST | 获取缓存值 | monitor:cache:view |
| /monitor/cache/clearCacheName | POST | 清除指定缓存名称 | monitor:cache:view |
| /monitor/cache/clearCacheKey | POST | 清除指定缓存键 | monitor:cache:view |
| /monitor/cache/clearAll | GET | 清除全部缓存 | monitor:cache:view |

### 业务规则与边界条件

- **缓存实现**：使用 EhCache，配置文件为 `ehcache-shiro.xml`
- **缓存名称**：系统使用的缓存名称包括字典缓存、参数缓存、登录记录缓存等
- **清除全部缓存**：clearAll 会清除所有缓存，包括字典缓存和参数缓存，清除后系统会自动重新加载
- **所有操作权限统一**：所有缓存操作使用同一权限 monitor:cache:view
