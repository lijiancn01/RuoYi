# 开发指南

## 新增业务模块标准流程

### 方式一：使用代码生成器（推荐）

1. **设计数据库表**：创建业务表，遵循命名规范（如 `biz_order`）
2. **导入表结构**：在代码生成器中导入表
3. **编辑生成配置**：设置包路径、模块名、业务名、模板类型
4. **编辑字段配置**：设置显示类型、查询方式、字典关联
5. **预览并生成代码**：下载或生成到自定义路径
6. **执行菜单SQL**：在数据库中执行生成的菜单插入语句
7. **分配权限**：为新菜单分配角色权限
8. **调整代码**：添加校验注解、数据权限、操作日志等
9. **测试验证**：功能测试、边界测试

### 方式二：手动创建

1. **创建数据库表**
2. **创建 Domain 类**：继承 BaseEntity，添加 @Excel 导出注解
3. **创建 Mapper 接口和 XML**
4. **创建 Service 接口和实现类**
5. **创建 Controller 类**：继承 BaseController
6. **创建页面**：列表页、新增页、编辑页
7. **插入菜单数据**：在 sys_menu 表中插入菜单和按钮记录
8. **分配权限**：为新菜单分配角色权限
9. **测试验证**

## 命名规范

### 包名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写，模块名分隔 | com.ruoyi.system |
| Controller包 | {packageName}.controller.{moduleName} | com.ruoyi.system.controller |
| Service包 | {packageName}.service | com.ruoyi.system.service |
| Service实现包 | {packageName}.service.impl | com.ruoyi.system.service.impl |
| Mapper包 | {packageName}.mapper | com.ruoyi.system.mapper |
| Domain包 | {packageName}.domain | com.ruoyi.system.domain |

### 类名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Domain | 实体名，驼峰命名 | SysUser, BizOrder |
| Controller | {Entity}Controller | SysUserController |
| Service接口 | I{Entity}Service | ISysUserService |
| Service实现 | {Entity}ServiceImpl | SysUserServiceImpl |
| Mapper接口 | {Entity}Mapper | SysUserMapper |
| Mapper XML | {Entity}Mapper.xml | SysUserMapper.xml |

### 页面文件名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 列表页 | {businessName}.html | user.html |
| 新增页 | add.html | add.html |
| 编辑页 | edit.html | edit.html |
| 详情页 | view.html | view.html |

### 权限标识规范

格式：`{模块}:{功能}:{操作}`

```
system:user:list     # 查询
system:user:add      # 新增
system:user:edit     # 修改
system:user:remove   # 删除
system:user:export   # 导出

```

## Controller 规范

### 模板

```java
@Controller
@RequestMapping("/module/entity")
public class BizEntityController extends BaseController {

    private String prefix = "module/entity";

    @Autowired
    private IBizEntityService bizEntityService;

    @RequiresPermissions("module:entity:view")
    @GetMapping()
    public String entity() {
        return prefix + "/entity";
    }

    @RequiresPermissions("module:entity:list")
    @PostMapping("/list")
    @ResponseBody
    public TableDataInfo list(BizEntity entity) {
        startPage();
        List<BizEntity> list = bizEntityService.selectEntityList(entity);
        return getDataTable(list);
    }

    @RequiresPermissions("module:entity:add")
    @Log(title = "实体管理", businessType = BusinessType.INSERT)
    @GetMapping("/add")
    public String add() {
        return prefix + "/add";
    }

    @RequiresPermissions("module:entity:add")
    @Log(title = "实体管理", businessType = BusinessType.INSERT)
    @PostMapping("/add")
    @ResponseBody
    public AjaxResult addSave(@Validated BizEntity entity) {
        return toAjax(bizEntityService.insertEntity(entity));
    }

    @RequiresPermissions("module:entity:edit")
    @GetMapping("/edit/{id}")
    public String edit(@PathVariable("id") Long id, ModelMap mmap) {
        mmap.put("entity", bizEntityService.selectEntityById(id));
        return prefix + "/edit";
    }

    @RequiresPermissions("module:entity:edit")
    @Log(title = "实体管理", businessType = BusinessType.UPDATE)
    @PostMapping("/edit")
    @ResponseBody
    public AjaxResult editSave(@Validated BizEntity entity) {
        return toAjax(bizEntityService.updateEntity(entity));
    }

    @RequiresPermissions("module:entity:remove")
    @Log(title = "实体管理", businessType = BusinessType.DELETE)
    @PostMapping("/remove")
    @ResponseBody
    public AjaxResult remove(String ids) {
        return toAjax(bizEntityService.deleteEntityByIds(ids));
    }
}
```

### 关键点

- 继承 `BaseController`，使用 `startPage()` 开启分页
- 页面跳转用 `@GetMapping`，数据操作用 `@PostMapping`
- `@RequiresPermissions` 控制权限
- `@Log` 记录操作日志
- `@ResponseBody` 返回JSON数据
- `toAjax(int)` 根据影响行数返回成功/失败
- 删除接口接收逗号分隔的ID字符串

## Service 规范

### 模板

**接口**：

```java
public interface IBizEntityService {
    List<BizEntity> selectEntityList(BizEntity entity);
    BizEntity selectEntityById(Long id);
    int insertEntity(BizEntity entity);
    int updateEntity(BizEntity entity);
    int deleteEntityByIds(String ids);
}
```

**实现类**：

```java
@Service
public class BizEntityServiceImpl implements IBizEntityService {

    @Autowired
    private BizEntityMapper bizEntityMapper;

    @Override
    public List<BizEntity> selectEntityList(BizEntity entity) {
        return bizEntityMapper.selectEntityList(entity);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public int insertEntity(BizEntity entity) {
        entity.setCreateBy(ShiroUtils.getLoginName());
        return bizEntityMapper.insertEntity(entity);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public int updateEntity(BizEntity entity) {
        entity.setUpdateBy(ShiroUtils.getLoginName());
        return bizEntityMapper.updateEntity(entity);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public int deleteEntityByIds(String ids) {
        return bizEntityMapper.deleteEntityByIds(Convert.toStrArray(ids));
    }
}
```

### 关键点

- 接口与实现分离
- 写操作加 `@Transactional(rollbackFor = Exception.class)`
- 新增时设置 `createBy`，修改时设置 `updateBy`
- 删除接口接收逗号分隔ID字符串，用 `Convert.toStrArray()` 转数组
- 数据权限查询方法加 `@DataScope` 注解

## Mapper 规范

### 模板

**接口**：

```java
public interface BizEntityMapper {
    List<BizEntity> selectEntityList(BizEntity entity);
    BizEntity selectEntityById(Long id);
    int insertEntity(BizEntity entity);
    int updateEntity(BizEntity entity);
    int deleteEntityByIds(String[] ids);
}
```

**XML**：

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
    "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.ruoyi.system.mapper.BizEntityMapper">

    <resultMap type="BizEntity" id="BizEntityResult">
        <id property="id" column="id" />
        <result property="name" column="name" />
        <!-- 其他字段 -->
    </resultMap>

    <sql id="selectEntityVo">
        SELECT id, name FROM biz_entity
    </sql>

    <select id="selectEntityList" parameterType="BizEntity" resultMap="BizEntityResult">
        <include refid="selectEntityVo"/>
        WHERE del_flag = '0'
        <if test="name != null and name != ''">
            AND name LIKE concat('%', #{name}, '%')
        </if>
        <!-- 数据权限 -->
        <if test="params.dataScope != null and params.dataScope != ''">
            AND ${params.dataScope}
        </if>
    </select>

    <insert id="insertEntity" parameterType="BizEntity" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO biz_entity (name, create_by, create_time)
        VALUES (#{name}, #{createBy}, #{createTime})
    </insert>

    <update id="updateEntity" parameterType="BizEntity">
        UPDATE biz_entity SET name = #{name}, update_by = #{updateBy}, update_time = #{updateTime}
        WHERE id = #{id}
    </update>

    <delete id="deleteEntityByIds" parameterType="String">
        UPDATE biz_entity SET del_flag = '2' WHERE id IN
        <foreach item="id" collection="array" open="(" separator="," close=")">
            #{id}
        </foreach>
    </delete>
</mapper>
```

### 关键点

- 主键用 `<id>` 标签，其他字段用 `<result>` 标签
- 公共SQL片段用 `<sql>` + `<include>` 复用
- 删除使用逻辑删除（`del_flag = '2'`），非物理删除
- 分页由 PageHelper 自动处理，Mapper 无需关心
- 数据权限 SQL 通过 `${params.dataScope}` 引用（注意是 `${}`）
- 新增使用 `useGeneratedKeys="true"` 回写主键

        var options = {
            url: prefix + "/list",

## 常见坑与避坑指南

| 坑 | 场景 | 原因 | 解法 |
|----|------|------|------|
| 分页不生效 | 列表查询返回全量数据 | `startPage()` 和查询方法之间有其他查询 | `startPage()` 必须紧跟查询方法，中间不能有其他查询 |
| 数据权限不生效 | 查询结果未按权限过滤 | Mapper XML 中未引用 `${params.dataScope}` | 在 WHERE 条件末尾添加 `<if test="params.dataScope != null and params.dataScope != ''">AND ${params.dataScope}</if>` |
| XSS校验报错 | 表单提交含特殊字符 | Domain 字段加了 `@Xss` 注解 | 富文本字段不加 `@Xss`，或在 xss.excludes 中排除该URL |
| 防重提交误拦截 | 用户快速双击提交按钮 | 默认5秒内相同请求被拦截 | 调整 `@RepeatSubmit(interval = xxx)` 或前端禁用按钮 |
| 字典不显示 | 下拉框无选项 | 字典缓存未加载 | 检查字典类型是否正确，调用刷新缓存接口 |
| 菜单不显示 | 新增菜单后页面看不到 | 未分配权限或未刷新 | 执行菜单SQL后分配角色权限，清除浏览器缓存 |
| 密码重试锁定 | 开发环境频繁登录失败 | 超过5次密码错误锁定10分钟 | 使用"登录日志-账户解锁"功能解锁 |
| 导入报错 | Excel导入数据失败 | 模板格式不匹配或必填字段为空 | 下载导入模板，确保字段格式和必填项正确 |
| 代码生成覆盖 | 重新生成代码覆盖修改 | `allowOverwrite=true` | 默认 `allowOverwrite=false`，生成后手动合并 |
| 逻辑删除查询 | 已删除数据仍被查到 | 查询条件缺少 `del_flag = '0'` | 所有查询SQL必须加 `WHERE del_flag = '0'` |
